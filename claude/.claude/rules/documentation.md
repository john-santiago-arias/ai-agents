# Documentation (always applies)

Universal documentation standards. Applies to every stack.

- JSDoc on exported interfaces reused across modules or representing API/store contracts.
- `@param`/`@returns` on exported functions in `utils`, `services`, `stores` when the signature alone is insufficient.
- Comments in English, describing intent — not obvious syntax. See the code-in-English rule (naming-english.md).
- Keep comments in sync with code changes.
